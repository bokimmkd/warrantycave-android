# WarrantyCave 1.0.34 (45) — Closed testing candidate

Open the app after the existing introduction without signing in. Free warranties remain local. Profile offers existing-account sign-in; selecting Basic/Plus leads to sign-in or account creation before purchase. Existing verified Free, Basic and Plus accounts remain supported.

Local data is migrated into separate account/guest storage with an atomic backup. Explicit guest sign-in transfers guest warranties once, merging with the account cache and paid cloud records. Sign-out hides that account’s records and returns to a clean Free guest workspace. Cloud access and billing still require a verified account; prices, limits, Firestore rules and backend authentication are unchanged.

## Automated validation

CI must pass analysis, the full Flutter suite including migration/ownership/login/offline cases, existing backend tests and Android unit tests before the candidate can be uploaded. Results are recorded in the linked Actions run; this document does not claim tests have already passed.

## Closed testing on real devices

- Upgrade from 1.0.33 without clearing app data: existing Free, Basic and Plus accounts retain local warranties/photos, settings and plan. Confirm existing Google and password sign-in.
- New install: introduction unchanged, then Home without login. Add/edit/delete Free warranties, reminders, Claim Pack and ads; restart offline.
- Profile sign-in to existing Free account; repeat with Basic/Plus. Restore purchases, verify plan and no ads. Logout/login and switch between two accounts: no cross-account records or notifications.
- Guest with warranties -> existing paid account with cloud warranties: both lists remain after restart/refresh; no duplicates. Repeat with temporary offline/cloud failure and subsequent recovery.
- New paid account: create/verify email, return from mail app, purchase/cancel/restore. Back from login/verification can continue local Free usage.
- Check Profile, Upgrade and verification screens in light/dark and all supported languages, including small screens.

Closed testing only. Production requires Boki’s test and approval. Do not uninstall or clear storage to install this update; use the Play testing update signed by Play.
