# WarrantyCave 1.0.39 (50) — Warranty details

Owner approved the compact warranty-details design and Closed testing.
Based on 1.0.38 (49), commit 959728323ac3fef68ae5661ce991839c8eda9078.

- All 12 existing details retain their original values and conditional visibility.
- Aligned two-column table with thin dividers; phone and email appear once and
  retain their call/mail actions.
- Product thumbnail is in the header and opens the existing zoom viewer.
- Receipt and warranty documents use compact thumbnail cards with access to all
  photos. Cards stack for narrow screens and large translated text.
- Preserve extended-warranty badge, product/category/status/remaining time,
  notes, edit/delete, PDF/share, navigation and safe areas.
- Add regression coverage for Plus-to-Free local-data preservation and account
  isolation. Logout remains different from subscription expiry.

No changes to authentication, cloud sync, plan limits, billing, prices, ad units,
stored data or backend deployment. Account-local warranty metadata is retained
after expiry. Remote-only photo URLs do not provide guaranteed offline images;
this release does not introduce permanent photo downloads or change cloud access.

Verification is pending CI; do not describe this candidate as device-tested.
Only upload to the existing Closed testing / Alpha track. Production requires
the owner's separate acceptance.
